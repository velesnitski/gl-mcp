Methodology

Developer adoption is the people-based industry headline: distinct non-bot commit authors with at least one AI-trailed commit in the window, divided by distinct non-bot commit authors overall (union across repos and teams — a developer active in several repos counts once). Automation identities ([bot], renovate, dependabot, CI) are excluded from both sides. AI commit share is commit-weighted: total AI-trailed commits / total commits across all scanned repos — unlike the per-repo averages it cannot be skewed by tiny repos. Both are telemetry lower bounds: trailers are the only visible signal, and squash-merges or disabled attribution hide real usage. AI-Active counts repos with config markers or any usage evidence — an AI-trailed commit on any branch (squash-hidden feature-branch usage counts), recent .tasks activity, or an AI-marked MR — so real adoption is not gated on config presence; Configured is the marker-based count (L1+). Levels: L0 no AI tooling markers; L1 Exploring any config marker (CLAUDE.md, AGENTS.md, .cursorrules, .mcp.json); L2 Practicing CLAUDE.md plus shared workflow assets (commands, settings, MCP config, hooks, or an ADR log) — or agents configured but not yet used; L3 Scaling agents plus measurable usage (≥10% AI-trailed commits, recent .tasks activity, or AI-marked MR descriptions). Usage is measured across all branches over the last 30 days because squash-merge strips commit trailers from the default branch; MR descriptions and .tasks/.claude path activity count as first-class evidence. In-flight repos have AI-named feature branches but no config merged yet. Trajectory: ↑ actively building (live AI branches or recent config/ADR maintenance), → steady use, ↓ markers present but unused and unmaintained. Attribution rate = share of adopting repos with usage evidence whose usage is visible via Co-Authored-By trailers. “Who” names the commit authors of trailed commits (top 3) and the AI tool parsed from the trailer itself; sample commits link to the evidence. Repos with no activity in 90 days are skipped as dormant and listed as archive candidates.
